```markdown
description: Revisa una propuesta u oferta comercial antes de enviarla al cliente. Marca cifras sin fuente, promesas fuera de alcance y fechas imposibles. Úsala cuando pidan revisar, auditar o corregir una propuesta.
---

# Revisor de propuestas

1. Lee la propuesta completa antes de marcar nada.
2. Para cada cifra, busca su fuente en el documento; sin fuente, es un hallazgo.
3. Para cada promesa, compárala con el alcance declarado; si lo excede, es un hallazgo.
4. Para cada fecha, compárala con el plan; si el plan no la sostiene, es un hallazgo.
5. Entrega una tabla: línea, hallazgo, arreglo. No reescribas la propuesta.
```
